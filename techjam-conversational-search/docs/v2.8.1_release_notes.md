# Shopping Copilot v2.8.1 Release Notes

## Outcome

This release completes the official Track 4 compliance pass without sacrificing the
v2.8.0 public hit rate.

| Metric | v2.8.0 | v2.8.1 |
|---|---:|---:|
| Hit Rate@10 | `0.995` | `0.995` |
| MRR | `0.573546` | `0.574935` |
| MTTC | `2.745` | `2.74` |
| Efficiency | `0.8255` | `0.826` |
| Technical Score | `0.834664` | `0.835180` |
| Model tokens / API cost | `0` / `$0` | `0` / `$0` |

Browsing, boundary, and intent-override Hit Rate@10 are `1.0`; Buying is `0.9875`.

## Track 4 changes

- Corrected the intent router so an explicit “still exploring” request remains Browsing
  even when it contains a category.
- Added state-driven transition from Browsing to Buying when the shopper supplies a hard
  slot or durable free-text constraint.
- Added distinct route weights: Buying emphasizes BM25 and verified constraint coverage;
  Browsing emphasizes dense discovery.
- Distilled anonymized `preference_tags` through a bounded allow-list and applied them only
  to the Browsing dense query. Rating metadata and prose summaries are excluded.
- Added bounded runtime context that combines long-term profile terms with current slots
  and durable evidence.
- Expanded optional LLM candidate cards with catalog category, feature, and price fields;
  ID membership validation and deterministic offline fallback are unchanged.
- Added focused route/context regression tests, an interactive terminal demo, an official
  compliance matrix, a Devpost draft, and a video recording script.

## Reproduce

Run from `techjam-conversational-search/`:

```bash
python -m evaluator.local_evaluator
python demo.py
python -m pytest -q  # after installing optional development dependencies
```

The remaining public miss is the same underdetermined novelty-shirt case documented in
v2.8.0. No label or sample-ID lookup was added.
