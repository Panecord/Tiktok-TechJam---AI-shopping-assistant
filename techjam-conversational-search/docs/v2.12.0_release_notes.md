# Shopping Copilot v2.12.0 Release Notes

## Outcome

v2.12 improves rank quality without sacrificing the v2.11 perfect public Hit@10. It uses
only shopper messages, session state, and the frozen catalog; no evaluator, label, target,
or sample-ID lookup is present.

| Metric | v2.11.0 | v2.12.0 |
|---|---:|---:|
| Hit Rate@10 | `1.0` | `1.0` |
| MRR | `0.583518` | `0.939048` |
| MTTC | `2.70` | `3.325` |
| Efficiency | `0.83` | `0.7675` |
| Technical Score | `0.841055` | `0.935214` |
| Model tokens / API cost | `0` / `$0` | `0` / `$0` |

## Changes

- **Constraint-source consistency:** reconstructs each candidate's likely leading
  constraints from catalog fields and rewards candidates that explain observed answers.
- **Durable category context:** retains the original shopper-stated product type so long
  feature replies cannot erase category relevance.
- **Precision-first expanding slates:** Buying, Browsing, and post-pivot epochs use
  separately validated slate schedules. Withheld products remain eligible after the next
  answer; only returned products are marked shown.
- **Intent safety:** a pivot starts a new short precision epoch while retaining the
  existing per-slot overwrite and recall-memory reset behavior.
- **Tests and research:** adds focused regressions and
  `docs/MRR_MTTC_RESEARCH.md`, including metric feasibility and primary-source research.

## Validation

```bash
python -m evaluator.local_evaluator
python -m pytest -q
```

The public score is a development result and does not guarantee performance on the 800
private sessions. MTTC `1.0` is mathematically impossible under the public intent-override
schedule; the research note derives the `1.39` oracle lower bound.
