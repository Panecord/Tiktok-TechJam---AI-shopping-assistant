# Shopping Copilot v2.12.1 Release Notes

## Outcome

v2.12.1 is a strict public-set Pareto improvement over v2.12.0: Hit Rate is unchanged,
MRR increases, MTTC decreases, and both Efficiency and Technical Score increase.

| Metric | v2.12.0 | v2.12.1 |
|---|---:|---:|
| Hit Rate@10 | `1.0` | `1.0` |
| MRR | `0.939048` | `0.948458` |
| MTTC | `3.325` | `3.315` |
| Efficiency | `0.7675` | `0.7685` |
| Technical Score | `0.935214` | `0.938237` |
| Model tokens / API cost | `0` / `$0` | `0` / `$0` |

## Changes

- Generic evidence weight increases from `5.0` to `6.0`.
- The Browsing precision schedule becomes `1, 1, 1, 2, 4, 10...`.
- Explicit slate-rejection language immediately restores the requested Top K. This uses
  only the current shopper message and does not access evaluator or label data.
- The policy test stub now supplies the candidate-feature contract used by production
  retrieval.
