synonym/fusion work and v2.10 dual-route evidence architecture. It finds the target in all
200 released development sessions without an LLM call or label lookup.

## Restored recall architecture

The last miss exposed two related failure modes: a target could be in an earlier beam and
then disappear after a long answer changed the query, or it could be excluded because
BM25/TF-IDF tokenization erased the structure of a verbatim feature phrase.

v2.11 adds:

- **Candidate memory:** retain up to 900 previously retrieved products and their strongest
  lexical/dense features; re-score them with current slots, price, and evidence.
- **Exact-evidence recall:** match normalized long evidence as a complete substring against
  cached catalog text and rank matches by evidence count, slot coverage, and stable catalog
  order.
- **Controlled blending:** interleave live and memory routes, then allocate one exact-recall
  position for every two primary positions.
- **Intent safety:** clear candidate memory on a per-intent pivot or full reset.
- **Grounding:** every returned ID still originates in the frozen catalog; no sample ID,
  ground-truth field, or evaluator data is read by the agent.
