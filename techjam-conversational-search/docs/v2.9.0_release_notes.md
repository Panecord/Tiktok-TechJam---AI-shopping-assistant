# Shopping Copilot v2.9.0 Release Notes

## Outcome

The deterministic agent now finds the target in all 200 released development sessions,
without an LLM call, sample-ID rule, or target lookup.

| Metric | v2.8.1 | v2.9.0 |
|---|---:|---:|
| Hit Rate@10 | `0.995` (199/200) | `1.0` (200/200) |
| MRR | `0.574935` | `0.572823` |
| MTTC | `2.74` | `2.71` |
| Efficiency | `0.826` | `0.829` |
| Technical Score | `0.835180` | `0.837647` |
| Model tokens / API cost | `0` / `$0` | `0` / `$0` |

All four scenario groups—Buying, Browsing, Intent Override, and Boundary—have public
Hit Rate@10 `1.0`.

## Candidate-memory route

The final v2.8.1 miss revealed retrieval drift: the target was present in the initial
category-conditioned beam, but disappeared after the shopper disclosed a long manufacturing
template shared by many catalog products. Exact-evidence reranking cannot recover a product
after retrieval has removed it.

v2.9.0 therefore:

- stores a bounded beam of up to 900 previously retrieved catalog candidates;
- retains each candidate's strongest observed lexical and dense retrieval features;
- activates memory only after a catalog-specific constraint of at least 40 characters;
- recomputes current slot, price, and evidence coverage for prior candidates;
- interleaves the separately ranked live and memory routes before unseen-slate selection;
- clears candidate memory on an intent pivot or full reset.

This is a label-independent Track 4 memory mechanism. Every memory candidate entered through
normal catalog retrieval, and the reranker still cannot invent an ASIN.

## Validation

Run from `techjam-conversational-search/`:

```bash
python -m evaluator.local_evaluator
python -m pytest -q
```

The public score is a development result, not a guarantee for the private 800 sessions.
When more than 100 products are indistinguishable from all disclosed information, no agent
limited to ten Top-10 slates can guarantee selecting an arbitrary hidden target. Candidate
memory improves systematic exploration without claiming otherwise.
