# Shopping Copilot v2.8.0 Release Notes

## Outcome

The default deterministic agent finds the hidden target in 199 of the 200 released public
sessions without an LLM call.

| Metric | Previous run | v2.8.0 |
|--------|--------------|--------|
| Hit Rate@10 | `0.650` | `0.995` |
| MRR | `0.478685` | `0.573546` |
| MTTC | `6.47` | `2.745` |
| Efficiency | `0.453` | `0.8255` |
| Technical Score | `0.559206` | `0.834664` |
| Model tokens | `0` | `0` |

Scenario Hit Rate@10 is `1.0` for boundary, browsing, and intent override, and `0.9875`
for buying. `results.json` contains the complete evaluator output.

## Changes

- Preserve arbitrary shopper constraints across later turns instead of retaining only a
  fixed set of material/color/size slots.
- Fold accumulated evidence into BM25 and TF-IDF/embedding query construction.
- Capture complete category phrases, including phrases containing `&`, without requiring
  every term to appear in a fixed category vocabulary.
- Scope simulated/direct answers to the attribute asked so incidental text such as
  “rubber sole” cannot overwrite a confirmed leather material.
- Preserve independent confirmed evidence through a per-slot intent pivot; reserve a full
  state wipe for explicit reset phrases.
- Prefer answerable clarification attributes, with entropy and profile tags as supporting
  signals.
- Return the strongest unseen grounded products before repeating an earlier slate.
- Add exact free-text evidence coverage to deterministic reranking.
- Stop double-counting broad category membership in the slot-match average.
- Replace stale fusion coefficients with the five-fold session-level means recorded in
  `validation_fusion_cv.json`.
- Forward recent shopper turns to the optional LLM reranker and keep immediate fallback on
  transport/HTTP failures.

## Validation

Run from `techjam-conversational-search/`:

```bash
python -m evaluator.local_evaluator
python -m pytest -q
```

The evaluator requires only Python 3.10+ standard library. `pytest` is an optional
development dependency listed in `requirements.txt`.

## Why the result is not reported as 100%

The single remaining public miss belongs to a large near-duplicate novelty-shirt group.
The simulator discloses a category and generic manufacturing template shared by hundreds
of products, but no title, saying, brand, or other identifier that selects one exact ASIN.
Adding a public sample-id/target lookup would produce label leakage and is intentionally
excluded. Private-set generalization should be evaluated separately from this development
score.
